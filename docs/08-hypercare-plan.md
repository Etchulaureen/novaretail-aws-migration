# 08 — Hypercare Plan

## Duration

72 hours for this lab.

## Monitor

Application availability, HTTP errors, EC2 CPU/status, RDS connections/CPU/storage, ALB target health, logs, security events and user incidents.

## Severity

- **P1 Critical:** service unavailable, data loss, major security incident
- **P2 Major:** major function degraded, multiple users affected
- **P3 Minor:** limited impact, workaround available

## Cadence

- First 4h: check every 15–30 minutes
- First 24h: frequent health reviews and business check-ins
- 24–72h: daily review and incident trend tracking

## Exit criteria

No open migration-related P1/P2 incidents, stable performance, monitoring active, business acceptance completed, handover documentation delivered.
